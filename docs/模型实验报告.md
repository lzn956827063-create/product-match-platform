# 商品匹配模型离线实验报告

本次完成了真实的 LightGBM 监督训练，与共享特征的规则基线比较。模型在 Abt-Buy 给定候选对分类上有提升，但不能用于证明中文手机的高精度 SKU 推荐效果，因此没有将其发布为默认业务模型。

## 数据与实验划分

来源为 DeepMatcher 官方公布的 Abt-Buy Textual 实验数据。记录表 A 有 1,081 条，表 B 有 1,092 条，官方训练/验证/测试对分别为 5,743 / 1,916 / 1,916。测试集正样本 206 对。

下载网址：<https://pages.cs.wisc.edu/~anhai/data1/deepmatcher_data/Textual/Abt-Buy/abt_buy_exp_data.zip>。

归档 SHA-256：`cd806d925aca21e6ab942b239353a10ee88904c59d3d3e3da6a74e364e9200a1`。每个 CSV 的摘要和来源在模型目录的 `data-manifest.json`。下载归档未附明确的数据许可，交付包不包含原始 CSV，通过登记脚本重新获取。

使用官方切分保持可比较性。训练与测试存在来源记录重叠，未声称这是未见实体泛化结果。验证集按左侧记录 ID 分组，再划为调参、校准和阈值选择三部分；切分索引已保存。这个分组无法替代完整实体分组，因此区间是探索性的。

字符 2–4 元 TF-IDF 只在训练对引用的文本上拟合。未标注的记录组合没有当作负样本。没有重采样，没有类别权重。名称、品牌、型号、规格和缺失特征与业务推理共用函数，价格不进入身份得分。

## 训练与策略

固定搜索预算为 4 组：num_leaves 15/31，max_depth 5/8；learning_rate 0.05，最多 350 轮，在独立调参分区早停。使用验证平均精确率选择参数。

随后分别训练 seed 42、43、44。在独立校准分区拟合 Platt 校准，在阈值分区选择分类 F1 最佳阈值，最后对冻结测试集报告一次结果。预先固定 seed 42 为导出模型，不按测试成绩选种子。

## 测试结果

| 模型 | Precision | Recall | F1 | Average precision |
| --- | ---: | ---: | ---: | ---: |
| 规则基线 | 0.2177 | 0.6214 | 0.3224 | 0.3255 |
| LightGBM seed 42 | 0.6130 | 0.7767 | 0.6852 | 0.7776 |
| LightGBM seed 43 | 0.6379 | 0.7184 | 0.6758 | 0.7703 |
| LightGBM seed 44 | 0.6387 | 0.7379 | 0.6847 | 0.7741 |

三个种子平均 F1 为 0.6819，标准差为 0.0043。训练与全部评测用时约 2.96 秒，不包含依赖安装与数据下载。

seed 42 共预测 261 个正例。按左侧记录分组 bootstrap 400 次，精确率 95% 区间为 [0.5576, 0.6630]。这不是完整实体分组的置信区间，不能推断企业总体准确率。

`metrics.json` 包含去掉规格特征、只用名称特征、去掉校准的消融结果和全部参数试验。`errors.json` 保存错误对索引、左右记录编号、真实标签、预测分数及决定，避免公开再分发原商品原文。

## 准入决定与后续验证

这组数据覆盖混合电子商品，手机严格规格字段大多缺失。规则基线为本项目的手机 SKU 基线，其跨品类分类成绩不能等同于业内针对 Abt-Buy 的最强基线。

分类阈值以 F1 选择，不是业务“高推荐”阈值。实际精确率显著低于方案的 98% 高推荐目标，并且给定对标签不能评价全流程候选召回及无匹配误推荐率。模型状态保持 EXPERIMENTAL，API 拒绝把它注册为可用生产策略。

下一轮应使用手机实体级完整关系，报告 Recall@20、首选精确率与区间、覆盖率、无匹配误推荐率和候选分差；比较同精确率下的覆盖率之后再决定模型准入。`ml/data/prepare_entities.py` 和 `ml/eval/retrieval.py` 提供相应构造与评测入口。当前没有执行完整 WDC 数据实测，不填造指标。
