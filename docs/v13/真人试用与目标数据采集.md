## 2. 真实数据资格与全库真值

运行工具：`python -m scripts.domain_error_analysis --input authorized-truth.json --output error-report.json --candidate-budget 20`。

输入结构见同目录 `目标领域真值空白模板.json`。必须填写来源类型、授权或公开许可依据、冻结的标准库和数据集哈希。每条查询要由独立核验人确认全库全部等价商品（无匹配时为空列表），填写依据，并标记全库已核对。仅对候选对打标签不满足此要求。

同一实体、别名和近重复组只能在一个 train / validation / test 分区。工具拒绝重复查询、跨分区近重复组、未核验全库及无来源依据的数据。错误分桶包括漏召回、排序、规格提取、缺资料和标准库覆盖；后三项需要独立人工诊断。

用于比较的候选预算与精度门槛保持一致；真实样本不足时继续规则与人工复核，不降低模型准入条件。许可和标注在工具中属于核验人的声明，需要企业另行审核。
