# 商品匹配平台操作说明

> 本文保留 1.0 交付的历史口径。1.1 的当前功能、接口变化和验证结果见 [优化版使用说明](优化版使用说明.md) 与 [优化交付验收报告](优化交付验收报告.md)。

平台输出的正式关系必须经过人工确认。操作分为准备标准库、导入供应商表、核对、导出四步。

## 准备标准库

使用管理员或数据专员账号进入“标准商品库”，选择“导入标准库”。支持 CSV、XLSX，CSV 可指定 UTF-8 或 GB18030。选择工作表和前 100 行内的表头，确认列与商品字段的对应关系。

标准库的内部编号、商品名称不能为空，内部编号在同一版本内不可重复。存在公式或字段内部冲突时需修正后重新导入。导入后为待发布版本，管理员发布后才能选择它执行匹配。后续维护选择“导入新版本”，旧版本保持可查询。

## 导入供应商表

在“匹配任务”选择“新建匹配任务”。上传文件后配置字段，名称必须映射。缺少来源编号时生成系统记录号，系统不合并重复来源记录。

校验页展示总行数、有效行数、错误行数及质量提示。空名称、公式等错误不进入运行，须勾选明确的排除范围；整表没有有效行时无法提交。质量提示不等于输入错误，关键字段缺失会影响之后的审核条件。

填写任务和供应商名称，选择已发布的标准库版本及匹配方案。确认后输入被冻结，后台计算。处理进度与审核状态分别统计。失败或取消的运行不能正式审核和导出，可从任务列表创建独立重试运行。

## 核对与审核

切换到另一位审核员。左边选择来源记录，中间查看原文、字段与提取来源，右边查看候选及对比。默认展示逐字段依据，技术分数位于折叠详情。

- 推荐匹配：字段完整且没有关键冲突，可以逐条确认，也可以明确选择最多 100 条进行批量人工确认。选择范围只包含明确勾选的条目，界面显示条数。
- 需复核：信息缺失或候选难以区分，补充资料或进一步核对；关键字段缺失时不能直接确认。
- 规格冲突：容量、颜色、地区、包装等存在明确差异，不能直接确认。可另选商品或由数据专员修正输入并重新运行。
- 暂无候选：只能说明当前没有找到候选，可使用“手动查找”搜索该运行绑定的标准库。

“退回补充”“标记当前未匹配”“撤销”以及对已有决定改选都需说明原因。撤销不删除历史。若提示记录已更新，页面会载入最新决定，请重新核对后再操作。

默认启用双人复核：批次创建者、修订创建者及运行提交者均不能审核自己的输入。管理员不会自动获得审核权限，需配置审核员角色；角色与双人复核规则分别检查。

## 导出与修订

点击“导出结果”，选择已确认映射或全量状态报告、CSV / XLSX 和是否保留原始列。确认页显示范围和条数。生成时冻结审核状态，之后的修改不会改变旧文件。

文件保留 30 天。“导出记录”会标识旧快照中有多少审核决定发生变化，需生成新文件获得当前结果。已下载文件不会自动被召回。XLSX 的编号单元格按文本输出，CSV 使用 UTF-8 BOM 并转义潜在公式文本。

数据专员在工作台点击“修正并新建版本”，上传修正后的完整表格。在任务列表的“新建运行版本”可以使用已有输入切换标准库或方案。工作台“版本比较”按同一批次的原始行号与来源编号对应记录；文件重排会显示为新增或移除，不能将它理解为可靠的自动实体合并。

## 组织管理

管理员可创建成员账号、调整多角色组合和停用成员。成员停用后，原访问令牌也无法继续访问该组织。至少保留一名有效管理员。

“匹配与复核”中保存的默认策略只影响后续运行。新建方案会创建独立策略记录。公开训练模型处于实验状态，需补充手机场景的完整准入评测后才能用于新的生产策略。
